This is an Android-only test beta. It is not a Play Store release.

1. If you have Graceroom test v33, v34 installs over it without uninstalling. If you have a test build older than v33, uninstall it first. This version will not update over those older installs.
2. On your phone, allow installs from this source (sometimes called unknown sources, or Install unknown apps).
3. Download the APK and open it to install.
