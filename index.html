Before you install

  1. This build is for Android phones only.
  2. If you have Graceroom test v33, this version installs over it without uninstalling. If you have a test build older than v33, uninstall it first. This version will not update over those older installs.
  3. Allow your phone to install apps from this source. That setting is sometimes called unknown sources, or Install unknown apps.
  4. Download the file, then open it to install.
